# 本地推荐命令行

这个入口调用现有 `/api/recommendations/stream`，不另写 Planner、记忆或检索算法。先启动原项目 API 及其已配置依赖；客户端本身不会启动服务、下载模型或回退到另一模型。

在仓库根目录执行：

```sh
python -m scripts.recommend_cli "外面下暴雨，想听安静但不压抑的音乐" --session-id listening-demo
```

每个返回事件占一行 JSON。歌曲到达立即输出，不等推荐解释；保留 exposure_id、dialog_state 等服务端字段。出现错误、中断或没有完成事件时，退出码为 1，已输出的歌曲只能视为部分结果，不伪造成功。

默认使用 `http://127.0.0.1:8000`、developer 隔离身份且禁止联网补充；**developer 不是绝对只读模式**，可以写开发隔离数据，但不应混入个人训练反馈。显式 `--personal` 才使用个人模式；`--web` 才允许联网补充。模型角色来自服务端配置，不强行选择云端供应商。`--profile-id` 仍须通过服务端档案校验。

`--session-id` 可复用服务端会话。Python 适配器 `recommend_events` 还支持传入 chat_history 与 dialog_state；CLI 目前不在本机保存聊天历史文件，跨进程历史能力取决于服务端 checkpoint，不能据此宣称完整离线聊天客户端。

只接受字面回环 IP，不支持公网 URL、不跟随重定向、不读取代理环境变量。远程多用户接入应使用独立的认证适配器，不能把任意 owner/profile 参数当作认证。

请求上限 64 KiB，单事件上限 1 Mi 字符，总等待默认 180 秒、最大 600 秒；连接超时 5 秒，写入超时 30 秒。读取等待使用同一总预算，避免正常较慢的 Planner 在 30 秒无输出时被客户端提前截断。不会自动重放不确定的推荐请求。Python 调用方若提前退出迭代，应使用 `contextlib.aclosing` 关闭流。

本地测试使用 HTTPX 假传输验证即时歌曲、上下文透传、错误/截断、超时关闭和禁止重定向；它们不等于真实模型的速度/质量验收。展示版仍有独立目录执行路径，尚未将其完全迁入主 API；该限制没有被这个命令行入口掩盖。
