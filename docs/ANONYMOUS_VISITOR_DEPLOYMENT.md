# 匿名访客身份（本地实现，待部署验收）

公网共享模式采用同源 HTTPS、服务端签名 Cookie。未开启 shared-safe/public-demo 模式时，本地档案行为不变。

## 部署配置

- `SOULTUNER_SESSION_SECRET`：独立随机密钥，至少 32 字符，在部署密文管理中设置；不可放入前端、仓库、日志或 NEXT_PUBLIC 变量。多实例使用同一密钥，重启保留；轮换会使全部旧访客 Cookie 失效。
- `SOULTUNER_PUBLIC_ORIGIN`：唯一公网 HTTPS origin，例如 `https://music.example.com`，不带路径。
- 前端与 API 通过同源代理访问；不要把内部 API 直接暴露公网。iframe 第三方 Cookie 受浏览器策略限制，本版优先独立同源站点，不保证跨站嵌入可用。

缺少有效配置时公网 API 返回 503，不退回 local_admin。当前未创建或部署真实密钥，也未操作创空间。

## 行为

前端统一 API 客户端先调用 GET /api/anonymous-session，一次页面生命周期共用初始化 Promise。Cookie 为 __Host 前缀、Secure、HttpOnly、SameSite=Lax、Path=/，有效期固定 30 天。过期或删除后需刷新初始化，会得到新身份，不能恢复旧记忆；有效期不是数据库自动删除期限。

服务端覆盖客户端 user_id/profile_id/interaction_mode；匿名数据不进入训练和 teacher 日志。访客的档案列表由服务端合成，仅包含自己。个人查询响应禁止共享缓存。Cookie 本身是持有者凭证，应防止泄露；不具备登录账户的跨设备恢复功能。

只开放已核对的访客路由。档案创建/管理、平台设置、网易账号、任务管理等不对匿名开放，管理员也不能在同一个访客入口绕过；本地管理保留。旧的记忆删除/合并管理路由尚未迁移为访客自助操作，因此仍拒绝。新路由默认拒绝，审核后才能加入。

两个自定义 SSE 代理已转发 Cookie、Origin 和 Sec-Fetch-Site。其它 API 走现有 Next.js rewrite。跨站 Origin/Fetch-Site 拒绝；生产反向代理必须保留这些头，不应自行伪造为可信值。

## 验证与尚未覆盖

ASGI TestClient 覆盖双访客、伪造 user_id/header、跨访客曝光反馈、Cookie 属性/签名/过期、跨站请求、管理路由、缺配置拒绝和本地模式。测试使用最小应用和真实身份中间件/上下文函数，没有连接真实音乐服务。

尚需生产浏览器同源端到端验收、访客自助清除记忆、Cookie 丢失体验、请求频率和并发配额、滥用防护与存储过期清理。不能把匿名隔离等同于完整公网运营安全。

## 后续本地补充：逐条删除与基础限流

已新增 POST /api/visitor/memory/forget，只接收 record_id，身份来自签名会话；记忆页访客删除按钮已接入。返回 tombstone/audit_history_retained，表示不再作为有效记忆使用，审计历史保留，并非物理抹除所有数据。用户不能通过此入口指定其他 user_id。批量清空、自动过期清理和物理删除仍未开放。

匿名入口现在每进程限制：总计 600 请求/分钟、最多 60 次新身份初始化/分钟、每访客 120 请求/分钟、每访客 10 次推理入口请求/分钟；每访客同时 1 个推理请求、进程同时 4 个。SSE 生命周期结束或取消才释放名额。返回 429/Retry-After。计数表最多 4096 项；过期回收，满时拒绝新计数项，不无限增长。

这是单进程入站控制，不强杀已运行的后台线程/GPU 请求；重启重置窗口，多 worker 会放大上限。未实现分布式配额、IP 防刷、请求体大小/输出 token/日额度限制，也不等同于完整 DDoS 防护。没有信任客户端可伪造的 X-Forwarded-For。
# 2026-09-07 补充

访客 POST 请求按实际接收字节限制为 64 KiB。Cookie 到期后客户端明确提示刷新，并停止自动请求；不会自动重放写操作到新访客身份。

`POST /api/visitor/memory/clear-learned` 接收空 JSON 对象，仅清空签名 owner 的学习偏好；SQLite 使用不受 UI 列表上限限制的批量删除标记，审计历史保留，手动画像不清除。尚不等于跨 Neo4j/GraphZep/Mem0 的账户物理删除。
# 请求体时限补充（2026-09-08）

单条记忆删除使用持久化恢复意图。主存储失败时返回 503，不报告成功；记忆页显示待处理数量，可通过签名 owner 约束的 `POST /api/visitor/memory/retry-deletions` 重试（空 JSON，每批 20 条）。未完成任务不等于已遗忘；这不包含 GraphZep/Mem0 精确删除及物理抹除，也不是多存储事务或自动定时重试。

共享匿名 POST 请求的 64 KiB 上限同时受 10 秒总接收时限保护；超时返回 408，慢速分块不会延长期限。此限制不适用于音乐文件上传接口，也不替代反向代理的连接数、头部大小与网络级超时保护。
